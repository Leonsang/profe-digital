# Taller 3 — Ecuaciones cuadráticas (Matemáticas, grado 10)

Resuelve cada ejercicio mostrando el procedimiento.

1. Resuelve por factorización: x² − 5x + 6 = 0
2. Usa la fórmula general para resolver: 2x² + 3x − 2 = 0
